# Security policy

Stridewell is a front-end demonstration, not a secure commerce application.

## Important warning

The demo admin credentials, authorization checks, application logic, and browser-stored data are visible to visitors. Do not use real passwords, payment details, personal information, or production customer data with this project. Do not rely on its client-side stock or preorder counter for real inventory.

## Reporting a vulnerability

Please do not publish sensitive personal information or working exploit details in a public issue. For this educational repository, report suspected issues through a private channel provided by the repository maintainer. If no private contact is listed, open a minimal public issue without secrets or personal data and ask the maintainer for a private reporting route.

## Production readiness

Before any real deployment, replace client-side authentication and storage with a secured backend, enforce authorization and inventory server-side, use a reputable payment provider, validate all inputs on the server, and review dependencies and hosting configuration.
